# 🏋️ Fitlog

Fitlog is a modern and responsive workout management web application designed to help users discover workouts, create a daily workout plan, and save their favorite exercises for later.

### 🌐 Live Demo

[FitLog Live Demo](https://web-fitlog.vercel.app/)

### 📦 Clone Repository

```bash
git clone https://github.com/Tamiim-Iqbal/FitLog.git
cd FitLog
npm install
npm run dev
```

## ✨ Features

- 🏋️ **Browse Workouts** — Explore different workouts and exercises.
- 📋 **Today's Plan** — Add workouts to your personal daily workout plan.
- 🔖 **Save Workouts** — Save workouts for later.
- 🔢 **Workout Counters** — Track planned and saved workouts.
- 📱 **Fully Responsive** — Works smoothly on desktop, tablet, and mobile.
- 🧭 **Responsive Navigation** — Mobile-friendly hamburger menu and desktop navigation.
- 🔔 **Toast Notifications** — Get instant feedback when performing actions.
- 🎨 **Modern UI** — Clean dark-themed interface with a lime accent color.
- 📄 **Workout Details** — View workout information such as duration and calories burned.
